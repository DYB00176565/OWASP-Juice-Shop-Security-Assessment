# OWASP Juice Shop – Web Application Security Assessment

## Project Overview

This project involved testing the OWASP Juice Shop web application to identify common security vulnerabilities and understand how they can affect web applications.

The assessment was carried out as part of a university cybersecurity project.

## Objectives

- Identify common web application vulnerabilities.
- Test authentication and access control.
- Analyse potential information disclosure.
- Understand how security testing tools detect vulnerabilities.

## Tools and Technologies

- OWASP Juice Shop
- OWASP ZAP
- Semgrep
- Browser Developer Tools
- SQL Injection testing
- SAST and DAST

## My Contribution

My work included:

- Investigating SQL Injection vulnerabilities in login functionality.
- Testing Broken Access Control.
- Identifying exposed files and sensitive information.
- Running static analysis using Semgrep.
- Performing dynamic security testing using OWASP ZAP.
- Reviewing findings and documenting potential security improvements.

## Key Findings

The assessment identified several security issues, including:

- SQL Injection vulnerabilities.
- Broken Access Control.
- Exposed files and information disclosure.
- Potential security risks identified through static and dynamic analysis.
